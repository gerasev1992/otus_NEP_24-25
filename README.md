# OTUS. Network Engineer. Professional. Labs



## 📘 Цели и задачи курса

### Курс предназначен для опытных специалистов, которые хотят перейти на продвинутый уровень работы с сетевыми технологиями.

* Главная цель: Подготовить сетевых инженеров, способных самостоятельно проектировать, настраивать, защищать и устранять неполадки в корпоративных сетях любого масштаба.

* Ключевые задачи: Дать практические знания по ключевым протоколам маршрутизации (BGP, OSPF, IS-IS, EIGRP) и технологиям безопасности (IPsec, VPN), а также развить навык быстрого поиска и устранения сложных неисправностей (troubleshooting).
